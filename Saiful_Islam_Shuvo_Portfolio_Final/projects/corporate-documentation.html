Project overview

Consistent documents. A repeatable mailing workflow.

The uploaded document is a project proposal for a fictional organization, North Star Trading Ltd. It describes a proposed set of reusable office-document templates and a Mail Merge workflow using an Excel recipient data source.

The proposal identifies the business problem as repeated manual typing and inconsistent formatting, and outlines a process to standardize documents and generate personalized letters.

Proposed deliverables
  • Company letterhead and business letter.
  • Office notice / internal memo.
  • Meeting agenda and minutes.
  • Sample employee appointment letter.
  • Excel recipient list with fictional records.
  • Word Mail Merge main document and personalized sample letters.
  • Short user guide for updating and repeating Mail Merge.
Tools & workflow skills
  • Microsoft Word styles, themes and page setup.
  • Margins, section breaks, headers, footers and page numbers.
  • Excel recipient data with structured column headings.
  • Mail Merge recipient selection, merge fields and preview.
  • Spelling, layout and output quality checks.
Project status: The uploaded file is the proposal / editable practice template. It defines the planned templates and Mail Merge outputs; it does not include the completed set of Word templates, Excel recipient workbook or final merged letters. This portfolio therefore presents it accurately as a proposal-stage practice project.
