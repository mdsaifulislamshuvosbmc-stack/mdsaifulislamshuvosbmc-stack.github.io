# Md. Saiful Islam Shuvo — Portfolio Website

## Files
- `index.html` — portfolio homepage
- `projects/` — three project detail pages
- `assets/` — profile photo and project preview images
- `downloads/` — original project files for visitors to inspect/download

## Preview locally
Open `index.html` in a browser. Keep the folder structure unchanged.

## Publish with GitHub Pages
1. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload the contents of this folder (not the outer ZIP folder) to the repository root.
3. In repository Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`.
4. Wait for GitHub Pages to publish, then visit `https://YOUR-GITHUB-USERNAME.github.io`.
